# 系统结构

## 1车

入口为 `vehicle-1/project/empty.c`。初始化 SysConfig、ICM45686、双电机、编码器、PID、OLED 和灰度模块后，通过按键选择 Q0–Q5。1车使用灰度路口标志和 IMU 航向执行分阶段循迹，并在 Q1–Q4 的关键节点向2车发送 Zigbee 命令。

1车业务循环没有启用 K230 接收，也没有启用/处理 Zigbee 接收；因此当前有效方向主要是1车向2车发命令。

## 2车

入口为 `vehicle-2/project/empty.c`。除共有外设外，还初始化逐飞 DL1B 距离传感器。主循环持续执行距离采样、K230 解析和 Zigbee 解析，并可运行 Q1–Q6。

2车控制包含三层输入：

- 灰度与 IMU：循迹、路口和转向状态。
- DL1B 距离：跟车距离外环。
- Zigbee/K230：题号启动、阶段停止以及 Q6 超车/停车事件。

## Q6

Q6 同时包含常规跟随、超车转向和停车分支。K230 用 `F1/F2/F3` 事件设置相应标志；2车在停车分支尝试向1车发送 `A6 A6`。当前源码中这条反向停止链路没有完整闭环，详见 [已知问题](known-issues.md)。
